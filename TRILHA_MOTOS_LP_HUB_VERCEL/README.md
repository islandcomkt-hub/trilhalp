# Trilha Motos — LP HUB

LP estática, responsiva e pronta para Vercel

## Publicar na Vercel

1. Extraia o ZIP
2. Envie a pasta para um repositório Git ou importe diretamente na Vercel
3. Em **Framework Preset**, escolha `Other`
4. Não configure comando de build
5. Defina o diretório de saída como `.`
6. Publique

## Desenvolvimento local

Execute `npm run dev` ou use qualquer servidor estático

## Estrutura

- `index.html` — conteúdo e SEO
- `style.css` — identidade, responsividade e motion
- `script.js` — entradas, vídeo e formulário de busca
- `assets` — logos, fontes, poster e vídeo
- `vercel.json` — cache e headers de segurança
